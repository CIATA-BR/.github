# Repositório institucional do CIATA

Este repositório concentra a apresentação pública e os padrões institucionais compartilhados pela organização `CIATA-BR` no GitHub.

## Conteúdo

- `profile/README.md`: perfil público da organização;
- `CONTRIBUTING.md`: orientações gerais de contribuição;
- `CODE_OF_CONDUCT.md`: regras de convivência e participação;
- `SECURITY.md`: política de relato responsável;
- `SUPPORT.md`: canais e limites de suporte;
- `ORGANIZATION.md`: divisão de responsabilidades entre `.github`, `CIATA-DS` e os produtos;
- `.github/ISSUE_TEMPLATE`: formulários compartilhados para issues;
- `.github/PULL_REQUEST_TEMPLATE.md`: template compartilhado de pull request.

## Limite de responsabilidade

Este repositório contém apenas materiais institucionais e padrões de colaboração no GitHub.

Padrões técnicos reutilizáveis, identidade, acessibilidade, engenharia, design, conteúdo e qualidade pertencem ao [CIATA Design System](https://github.com/CIATA-BR/CIATA-DS).

Documentação específica deve permanecer no repositório do produto correspondente.

## Princípio

> **Transformando experiência em patrimônio coletivo.**
