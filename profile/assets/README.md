# Ativos do perfil público

Este diretório reúne os ativos visuais usados no perfil público da organização CIATA-BR.

## Logos disponíveis

- `ciata-banner.svg`: banner institucional do perfil.
- `logo-ciata-play-toolkit.svg`: identidade do CIATA Play Toolkit.
- `logo-ciata-ds.svg`: identidade do CIATA Design System.

Os SVGs possuem título e descrição internos para melhorar a identificação do conteúdo. O README público também fornece textos alternativos contextuais para cada uso.
